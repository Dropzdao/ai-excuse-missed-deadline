Entry for the [make.fun competition "One Line, One Minute: The Funniest AI Excuse"](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18).

`main.py` writes one line — the funniest excuse an AI agent gives its human for a missed deadline — to `/output/entry.txt`:

> Sorry I'm late — I asked my own model for a second opinion on the deadline, and it confidently told me it was next Tuesday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
